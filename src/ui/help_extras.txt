WRAPPER OVERVIEW
  codex-session wraps `codex` with persistent CODEX_HOME, profile-layered
  session composition, multi-account support, and quota-aware selection.

WRAPPER VERBS
  version       Print wrapper and child version details.
  completion    Generate a shell-completion script.
  config        Operate on wrapper-owned config (subcommand: status).
  profile       Inspect and compose wrapper-owned profiles.
  doctor        Run full validation of the codex-session setup.
  account       Manage codex-session accounts (subcommands: add, list,
                current, use, remove, refresh, quota, cooldown).

PASSTHROUGH
  Any verb not listed above is forwarded verbatim to `codex` (e.g. exec,
  apply, resume, fork, review, login, logout, mcp, plugin, ...). Use `--`
  to disambiguate flags that would otherwise be claimed by the wrapper.

ACCOUNT MANAGEMENT
  codex-session account add work
  codex-session account list
  codex-session account quota --format json
  codex-session account use work
  codex-session --account work exec "hi"
  codex-session --account auto exec "hi"

ENV VARS
  CODEX_SESSION_GROUP          Override the resolved group-id.
  CODEX_SESSION_ACCOUNT        Override the resolved account.
  CODEX_SESSION_CHILD_BIN      Override the wrapped codex binary path.
  CODEX_SESSION_ACCOUNT_PINNED, CODEX_SESSION_ACCOUNT_REGISTRY_DIR,
  CODEX_SESSION_ACCOUNT_QUOTA_TTL_SECS, CODEX_SESSION_ACCOUNT_WEEKLY_FLOOR,
  CODEX_SESSION_ACCOUNT_FIVE_HOUR_THRESHOLD  Account config overrides.

SEE ALSO
  Run `codex --help` for codex's own verbs and flags.
