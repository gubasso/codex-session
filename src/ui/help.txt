codex-session — wrapper around `codex` that keeps ~/.codex/config.toml in sync
with the stow-managed ~/.codex/config.base.toml while preserving machine-local
sections (e.g. [projects."..."]).

Usage:
  codex-session
  codex-session help
  codex-session version [--format <fmt>]
  codex-session config status [--format <fmt>]
  codex-session config merge
  codex-session config show-local [--format <fmt>]
  codex-session [<codex verb> ...]
  codex-session -- [<codex args> ...]

Wrapper verbs:
  help                 Show this message.
  version              Print codex-session wrapper + resolved child version.
  config status        Print base/target/stamp paths and whether a merge is needed.
  config merge         Force re-merge regardless of stamp freshness.
  config show-local    Print machine-local TOML sections that would be preserved.

Wrapper options:
  -v, -vv, -vvv        Raise wrapper log verbosity (info / debug / trace).
                       Overridden by RUST_LOG when that env var is set.
      --log-stderr     Mirror the wrapper log to stderr in addition to the
                       structured JSON log file.
      --version        Print wrapper + child version and exit.
      --format <fmt>   Output format: `text` (default) or `json`.
                       Honored by: version, config status, config show-local.
      --dry-run        Print the resolved child invocation (binary,
                       argv, scrubbed env diff) and exit 0 without
                       running the child.

Environment:
  CODEX_SESSION_CHILD_BIN   Explicit path to the inner `codex` binary.
                            Tried before PATH lookup.
  CODEX_SESSION_LOG_FILE    Full path to the wrapper's structured log file.
  CODEX_SESSION_LOG_DIR     Directory holding `codex-session.log`.
                            Used only when CODEX_SESSION_LOG_FILE is unset.
  CODEX_SESSION_REENTRY     Re-entry marker set on the child env to
                            detect chained-wrapper loops. Refuses to
                            start the wrapper when set to `1` in the
                            parent env.
  RUST_LOG                  Standard `tracing` filter; overrides -v.
  NO_COLOR                  Disable ANSI colors on the stderr mirror.

Any subcommand not recognized by the wrapper is forwarded verbatim to the real
`codex`. Use `--` to force pass-through of `-`-prefixed arguments.
